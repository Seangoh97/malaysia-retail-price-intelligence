# Malaysia Retail Price Intelligence

An executable R tool for comparing Malaysian retail quotes with supported, item-specific historical price benchmarks.

**Working analytical prototype · July 2026 reference month · nine items · five formats · two regions**

## What you can do

- Generate conditional geometric price benchmarks for 90 item × format × region combinations.
- Compare your own quotes with those benchmarks, preserving item units.
- Review observed price ranges, premise-clustered uncertainty, held-out validation and input-quality checks.
- Rerun the analysis from frozen, checksummed official inputs.

The current run used **185,143 observations across 2,110 premises**. All outputs in `results/` were generated by the new pipeline. The old coursework notebook and report are not part of this release.

## Quick start

Run commands from the repository root. Use R 4.6.1 for the recorded environment; Pandoc and R Markdown are not required.

```r
install.packages("renv", repos = "https://cloud.r-project.org")
renv::restore(prompt = FALSE)
```

```sh
Rscript scripts/unpack.R
Rscript scripts/verify_inputs.R
Rscript scripts/run.R 2026-07
Rscript tests/run-tests.R
Rscript scripts/score.R examples/quotes.csv results/scored-quotes.csv
```

The exact tested inputs and trained model are stored in `project-bundle.zip`. The unpack command restores their original paths and checks input hashes; the source code and evaluation results are browsable directly in the repository.

Open **`results/report.html`** in a browser for an offline run summary. Read `results/basket.csv` for supported item codes and units, and `results/benchmarks.csv` for all benchmark cells. `results/scored-quotes.csv` shows a quote's percentage difference from the model benchmark. Example quotes are synthetic inputs, not market observations.

If exact environment restoration is unavailable, install `dplyr`, `readr`, `sandwich`, `jsonlite` and `digest` from CRAN. This may yield different results; record your session and rerun validation.

## Validation results

Basket selection used only 1–24 July observations from development premises. Premises whose code is divisible by five were withheld from fitting. The model was evaluated on 25–31 July, separately for known and held-out premises. This is a deterministic holdout, not a randomized representative sample.

| Evaluation | Rows | Model log MAE | Item-only baseline log MAE | Median absolute percentage error |
|---|---:|---:|---:|---:|
| Later dates, known premises | 35,129 | 0.1988 | 0.2153 | 14.74% |
| Later dates, held-out premises | 7,904 | 0.1935 | 0.2066 | 14.44% |

The baseline uses the training mean log price for each item. Model log MAE was lower by about 7.7% and 6.3%, respectively. The final benchmark model refits on all July observations for the frozen selected basket; validation evaluates the development model. These results do not establish accuracy in later months or unmonitored locations.

## How the model works

The log-linear model controls for item identity, includes format × region interactions and allows regional differences by product group. It uses every retained observation for the selected basket rather than taking a small random sample. Inference uses HC1 sandwich standard errors clustered by premise and t reference quantiles with G−1 degrees of freedom.

Eligibility requires all ten format × region cells, each with at least 30 quotes from three distinct premises in the development set. The most observed item per category is chosen, then up to four categories per group. The data support nine items: four dry-produce, four fresh-produce and one packaged-good item. The packaged category is therefore especially narrow.

## Important limits

This is a **historical benchmarking tool**, not a current-price feed, automated pricing recommendation, causal model or production-certified service. PriceCatcher item definitions can cover product quality differences; check descriptions and units before comparing. The confidence intervals describe uncertainty in a conditional geometric mean, not individual-price prediction intervals. Prices vary across items and premises beyond the factors captured here.

The lookup snapshots were downloaded after July and can misrepresent historical classifications. The current item lookup leaves 25,423 raw transaction rows unmatched; these are excluded and counted in the manifest. No claim is made that the original coursework results were reproduced. See the [model card](docs/model-card.md) and [validation notes](docs/validation.md).

## Project structure

```text
R/core.R                  Validation, preparation, model and scoring functions
scripts/run.R             End-to-end pipeline
scripts/score.R           Compare a CSV of quotes
scripts/verify_inputs.R   Verify frozen inputs against SHA-256 manifest
scripts/download.R        Restore exact input bytes where still available
examples/quotes.csv       Synthetic quote examples
tests/run-tests.R         Data-contract and numerical checks
data/raw/                 Frozen official CSV inputs
data/input-manifest.json  Sources, hashes and snapshot notes
results/                  Generated model, report, metrics and CSV outputs
docs/                     Model card and validation notes
renv.lock                 Recorded R package environment
```
